# Proyecto 3 - Chatbot Inteligente con Programación Lógica

## Ejecutar
```bash
swipl main.pl
```

## Estructura
- `main.pl` — punto de entrada, y entrada de linea.
- `conocimiento.pl` — base de conocimiento estatico.
- `inferencia.pl` — motor de razonamiento y respuesta
- `nlp.pl` — convierte el texto en términos Prolog.
- `data/` — conocimiento aprendido que persiste
